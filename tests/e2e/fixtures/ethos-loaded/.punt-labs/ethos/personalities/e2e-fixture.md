# E2E Fixture Persona

This identity exists only to prove that the L4 (Wire Observability) test
tier can see ethos's own SessionStart injection on the wire. It carries
no real responsibilities and represents nobody at Punt Labs.

## Core Traits

- Deterministic: the same fixture produces the same bytes on every run.
- Minimal: one identity, one personality, one writing style, one
  talent, one single-member team — just enough to exercise every
  attribution bucket `cmd/e2e-attribute` reports.
