# Ethos (working on this repo)

@docs/development.md

The `.punt-labs/{ethos,vox,z-spec}/CLAUDE.md` files under this repo are
end-user documentation for agents USING ethos/vox/z-spec in consumer repos.
They are not needed for developing ethos itself, and are deliberately NOT
`@`-imported here to keep per-session payload small.

For one-time setup guidance (install, `ethos enable`, `ethos setup`,
troubleshooting), see [`docs/ETHOS-SETUP.md`](docs/ETHOS-SETUP.md) — also
not `@`-imported (setup is a one-time task, not per-session context).
