# Quarry recall

Inspect the live Quarry tool schema or `quarry --help` before choosing a query.
Search bounded task terms, issue IDs and relevant ADRs. Read matching documents,
preserve source/date/provenance and distinguish memory from current authority.
Verify stale claims against current PR/FAQ, specs and code. No matches is a valid
result; transport/index failure is not no matches. Report the exact prerequisite
when unavailable. Never dump a whole private collection into context or print
credentials. This adapter does not write memories or source files.
