# Ethos consumer reference

Read docs/agent-guide.md on demand for the maintained consumer CLI/MCP guide.
If it is not present, report the missing relocation rather than inventing a
contract. Use `ethos --help` and relevant `schema` subcommands for the installed
version. This guide is reference, not mandatory mission orchestration for the
authorized repair; docs/opencode-workflow.md defines that exception.

Read docs/ETHOS-SETUP.md only for an explicit product setup task. Do not install,
enable, seed, start missions or mutate existing records merely to answer a
question. Run product acceptance in isolated task-owned fixtures and preserve
the current repo's records/environment. Native OpenCode sessions are not Claude
lifecycle hooks or the unimplemented DES-078 adapter. Surface failed/absent
prerequisites and use only tested evidence in the final task result.
