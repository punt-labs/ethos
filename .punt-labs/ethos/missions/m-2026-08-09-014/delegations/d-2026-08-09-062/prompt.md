**2. [Confirmed by 2 of 3 reviewers, security-relevant] `digestSection` truncates to 8 hex chars BEFORE comparing, not just for display.**
`internal/doctor/doctor.go`'s `digestSection` returns a truncated 32-bit digest, and `CheckHookCurrency` compares those truncated values directly (`installedDigest == expectedDigest`). This collapses the comparison from full SHA-256 collision resistance down to a 32-bit birthday bound — an unforced, uncompensated weakening of the exact mechanism this feature exists to make trustworthy. The design doc (docs/design-hook-drift-detection.md, "Normalizing before comparing") specifies comparing full digests and truncating only for the report line. Fix: compute and compare the full `[32]byte` SHA-256 sum; truncate only when formatting the `Detail` string.

**3. [code-reviewer, confidence 84] A hook section masked by an unterminated heredoc reports false PASS.**

Fix: check for an unterminated-heredoc condition before calling `InstalledSection` in `CheckHookCurrency` and return FAIL with wording consistent with `Chain`/`Unchain`'s existing refusal message.
